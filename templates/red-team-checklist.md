# Red-Team Review Checklist

Run on a **different day** from drafting. Your job is to disqualify this bid.

**Tender:** ____________  **Reviewer:** ____________  **Date:** ____________

## Stage 1 — Kill checks (fatal)
- [ ] Closing date/time correct; internal cut-off met
- [ ] Correct submission method, address or portal
- [ ] Compulsory briefing attended; certificate included
- [ ] Bid validity accepted; offer not qualified or conditional
- [ ] Every mandatory returnable present
- [ ] All forms signed, dated, initialled, witnessed as required
- [ ] Authorised signatory + resolution/POA included
- [ ] Correct legal entity used consistently throughout
- [ ] CIDB grade, class and active status correct
- [ ] Tax status compliant; CSD current; not restricted
- [ ] No blank rate or unpriced item; totals carried correctly
- [ ] Latest corrigendum version used and acknowledged
- [ ] No prohibited alterations; corrections initialled

## Stage 2 — Scoring checks
- [ ] Every criterion answered under its own heading, in the tender's order
- [ ] Every claim has cited, attached, paginated evidence
- [ ] Experience comparable in nature, value and recency
- [ ] Key personnel meet stated qualification/registration/years
- [ ] Programme consistent with contract completion date
- [ ] Methodology site-specific: numbers, names, references in every paragraph
- [ ] Self-score completed against the tender's own scale

## Stage 3 — Consistency checks
- [ ] Names, dates, values and quantities identical across all documents
- [ ] Programme ↔ resources ↔ cash flow ↔ BOQ preliminaries agree
- [ ] Team in methodology matches CVs and org chart
- [ ] No text left over from another bid (search previous client names)
- [ ] No `MISSING — CLIENT TO PROVIDE` remaining

## Stage 4 — Packaging
- [ ] Document order matches the tender's index
- [ ] Pagination, index, dividers, labelling as instructed
- [ ] Correct number of copies; originals vs copies marked
- [ ] Envelope labelling exact; two-envelope separation if required
- [ ] Electronic format, file naming, size limits; upload confirmed
- [ ] Proof of submission retained
