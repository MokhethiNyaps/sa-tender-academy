# Final Submission Checklist

**Tender:** ____________  **Closing:** ____________  **Internal cut-off (D-3):** ____________

## 72 hours before
- [ ] Re-check the portal for corrigenda — record date/time checked
- [ ] All compliance matrix rows closed or explicitly accepted as risks
- [ ] All third-party documents received and in date at closing AND likely award
- [ ] Priced BOQ received; arithmetic audit complete; zero blanks
- [ ] Red-team defects all closed

## 24 hours before
- [ ] Final print / final PDF compiled in the tender's document order
- [ ] Index and pagination complete
- [ ] Signatures, initials on every page where required
- [ ] Copies produced and labelled
- [ ] Envelopes labelled exactly per instruction; two-envelope separation if required
- [ ] Delivery route, parking, access and building security planned
- [ ] Electronic upload tested (file size, format, naming)

## At submission
- [ ] Deposited at the correct box/counter/portal
- [ ] Receipt / register signature / upload confirmation obtained and saved
- [ ] Photograph of submission and tender box (physical submissions)
- [ ] Submission logged in `worklog/tender-log.csv`

## After submission
- [ ] Full copy archived in `05-final-submission/`
- [ ] Debrief note written; Tender Bible and error log updated
- [ ] Diarise expected award date; monitor eTenders awards
- [ ] Request buyer debriefing if unsuccessful
